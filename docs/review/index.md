# 每日复习

目标：避免孩子只靠选择题猜答案，改成**主动语音回答**。

## 每日流程

### 1. 英文 → 中文

家长或孩子打开词库，看到英文后说中文意思。

示例：

> discover

孩子说：

> 发现 / 找到

### 2. 中文 → 英文

看到中文后说英文。

示例：

> 花粉

孩子说：

> pollen

### 3. 句子理解

听一句英文，说出大意。

> Bees carry pollen from flower to flower.

孩子说：

> 蜜蜂把花粉从一朵花带到另一朵花。
