## 推荐使用顺序

1. 每天先打开 **词库总表**，选 10–20 个词。  
2. 用 **语音回答复习** 做主动回忆：英文说中文，中文说英文。  
3. 每周用 1–2 篇 **听力故事** 练听力和理解。  
4. 读完故事后，用 **口语复述表** 让孩子讲出来。
