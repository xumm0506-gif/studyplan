# 口语复述对照表

适合打印，贴在孩子书桌旁。读完一本书后，让孩子按下面句型复述。

| 复述目标 | 英文句型 | 中文提示 |
|---|---|---|
| 说故事主题 | This story is about... | 这个故事是关于…… |
| 说故事地点 | The story takes place in... | 故事发生在…… |
| 说人物 | The main character is... | 主要人物是…… |
| 说一开始 | First, ... | 首先，…… |
| 说接着发生 | Next, ... | 接着，…… |
| 说然后 | Then, ... | 然后，…… |
| 说最后 | Finally, ... | 最后，…… |
| 说人物在做什么 | He / She is trying to... | 他/她正在努力…… |
| 说原因 | ... because ... | ……因为…… |
| 说感受 | I think... | 我觉得…… |
| 说喜欢的部分 | My favorite part is... | 我最喜欢的部分是…… |
| 说自己的观点 | I like... because... | 我喜欢……因为…… |
| 说如果是我 | If I were in the story, I would... | 如果我是故事里的人，我会…… |
| 结束复述 | That is the end of the story. | 这就是故事的结尾。 |

## 简短复述模板

| 版本 | 英文模板 | 中文提示 |
|---|---|---|
| 基础版 | This story is about... First,... Then,... Finally,... | 主题 + 三步讲完 |
| 进阶版 | The story takes place in... The main character is... He / She wants to... Finally,... | 地点 + 人物 + 目标 + 结尾 |
| 挑战版 | I think... because... If I were in the story, I would... | 观点 + 原因 + 自己会怎么做 |
